Data — quality gates on every training row

  • Feed gate — kiln feed > 461 t/h: never learn from shutdowns/upsets.
  • Analyser purge masking — CO/O₂ valid only when RUN=1 & O₂<15% (~9% of readings are purge artefacts; upstream IQR cleaning proved equivalent to our gates — identical 388k rows).
  • Dead-tag ban — tags present in history but dead on the live server are excluded by rule (they'd invalidate every live row).
  • Forward-gap guards — a t+5 label must truly be 4–7 min ahead; gaps can't fake targets.
  • Chronological splits only — 70/15/15 by time; random splits leak adjacent minutes.
  • 3 data bugs found & fixed — timestamp-format clash silently dropping ALL live rows; features on dead tags; the K3V10F1 tag typo that hid the AFR damper for a month. Each is now a permanent pipeline guard.

Models — the race (identical data, identical splits)

The serving model is a 0.6·GBT + 0.4·ARX blend per horizon: the trees are sharp, the linear model is regime-stable, and their errors differ in shape — the blend beat either alone at every horizon and matches the measured ensemble ceiling.

Bias patterns (measured)
+1.9 → ~0 °C

Systematic +1.9 °C drift found & self-corrected (rolling 2 h offset vs the raw model). Anchoring: corr 0.91 with now vs 0.59 with future. Damping 0.44 on big moves — the known weakness; big-move detector is the planned fix.

The guarded weekly retrain: ingest live minutes → train → promote only if not worse → reload. Six promotions, two fully unattended, zero interventions.

How far ahead can it see? — t+1 → t+30

At t+1 the twin scores 3.36 °C — but one minute out the plant has barely moved (persistence 3.87), so the edge is small. Skill grows with horizon, peaking ~26% at t+10: the twin is most valuable exactly where a human can't extrapolate. The optimizer plans on the full t+5…t+30 trajectory with P10–P90 chance constraints.

The floor — why ~6° is near the physical limit

~0.7 °C of every score is thermocouple jitter on the truth itself; the test-picked ensemble ceiling equals what v7 already serves; the unexplained remainder is minute-scale fuel calorific-value variation no current sensor measures. Below ~5.5 °C is an instrumentation decision (online AFR fuel-quality sensing) — not a modelling one. Next value step instead: surface the advisory in the CCR and measure followed-vs-ignored ₹/day.
